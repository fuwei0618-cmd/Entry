# Entry · Minion 森林之家

小瑋 Ellie 的個人總入口。一個可以走進去的 3D 森林與家，每個地方通往一個工具或手冊。

- 網址：https://fuwei0618-cmd.github.io/Entry/
- Repo 名稱 `Entry` 是固定的技術名稱，**不要改**（改了網址會失效）。
- 正式名稱目前是「Minion 森林之家」，改名時改兩個地方：
  1. `index.html` 裡的 `const APP_NAME=`（畫面上的名字）
  2. `manifest.webmanifest` 的 `name` 和 `short_name`（手機主畫面的名字）

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 全部程式（場景、角色、介面） |
| `three.min.js` | 3D 元件（three.js r128），存在 repo 裡不依賴外部網站 |
| `manifest.webmanifest`、`icons/` | 加到主畫面時的名稱與圖示 |
| `versions/` | 過去版本的存檔 |

## 場景與意義
| 場景 | 地方 | 代表 |
|---|---|---|
| 森林 | 記錄之河 | 無時無刻的自我記錄，所有作品的原料 |
| 森林 | 蘑菇攝影棚 | 自媒體：從河裡撈素材，用萬用公式（積木）組成作品 |
| 森林 | 螢火蟲 | 通訊錄：每一點光是一個有連結的人 |
| 森林 | 營火 | 鐵粉：被熱情吸引過來的人，不一定是先認識的 |
| 家 1F | 日曆牆、廚房、衣帽間、健身房、金庫、Lucky | 每日每週排程、飲食、穿搭外型、身體、理財保險、毛孩 |
| 家 2F | 臥室、書桌、白水木 | 作息睡眠、睡前記錄 |
| 閣樓 | 禱告房、轉運流水盆 | 信仰、信念、晨間宣告 |
| 舞台（從家裡的舞台門進入） | 主唱麥克風、合唱台、Podcast 桌、觀眾燈海 | 唱歌、合唱團、不專業音樂電台、為眾生 |
| 世界之門（家裡後牆） | 旅遊手冊 World | 旅行 |

原則：森林保持安靜；舞台與世界之門這些「外放」的地方，只能從家裡的門進去。

## 操作
點地面走過去、拖曳轉視角、電腦 WASD / 方向鍵、E 互動、右上角切換第一 / 第三人稱與快速移動。
